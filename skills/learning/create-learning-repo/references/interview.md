# Goal discovery

Use these questions only when the answer would materially improve the plan and is not already available. Infer reasonable defaults and proceed when the user asks you to make a judgment. Batch necessary questions without making an interview a prerequisite for work.

| Missing context | Useful question |
|---|---|
| Outcome | What would you like to be able to do with this subject? |
| Starting point | What can you already do without help? |
| Constraints | Is there a deadline, time budget, or required syllabus? |
| Depth | Is the priority broad familiarity or a smaller set of working skills? |
| Assessment | What would demonstrate progress: a project, explanation, exam, or real-world result? |
| Scope | Are there topics to include or deliberately leave out? |

A goal can be exploratory. “Understand the basics and find what interests me” can support a useful first plan without inventing a career endpoint.

Infer a profile from the goal: technical judgment, craft, sustained practice, or exam performance. Use a custom progression when the presets do not fit. State important assumptions so the user can correct them, without requiring confirmation for routine choices.

Ask about public writing or a long-term career arc only when it affects this request. Select optional files only when they serve the goal. Fit schedules and effort estimates to available context, and avoid false precision.

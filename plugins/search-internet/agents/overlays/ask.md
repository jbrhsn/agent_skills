## Capability: search-internet

`web_search_tool` searches the live web. Use it together with `webfetch` for questions about external libraries, current versions, or anything outside this repo — search to find the right sources, fetch to read one in full.

Prefer the repo tools for repo questions; reach for the web only once you have established the answer is not in the codebase. Cite the URLs you actually relied on, the same way you cite `path/to/file:line` for local findings.

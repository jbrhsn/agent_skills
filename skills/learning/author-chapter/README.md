# Author Chapter

Turn a small note or stub into a complete learning chapter, or revise teaching material at the depth the learner needs. The skill also supports standalone tutorials, guides, assessments, and files from a learning repository.

## Approach

The agent reads an existing stub before outlining or drafting. If it is missing, empty, or only placeholders, it uses direction already supplied in the conversation or brief. If the topic or learning goal is still missing, it asks for only that information before drafting.

Unless another audience is specified, the chapter should be accessible to a curious 15-year-old new to the topic, with unfamiliar language and essential prerequisites explained. A compact internal coverage map connects the learning goal to core concepts, necessary adjacent topics, application, and limits. Completeness means meeting that goal, not covering every related subject.

The skill uses 80/20 as a prioritization heuristic: concentrate on concepts and practical patterns that contribute most to the learning goal, while teaching their prerequisites fully. It does not impose a numerical split or sacrifice requested coverage. Final review cuts or shortens material that adds no meaningful understanding, application, or judgment.

The default reading experience is a well-written explanatory blog post with connected reasoning and topic-specific headings. Complete modules with practical goals include a demonstrated application, a meaningfully different case to attempt, and a way to assess the result. These are teaching outcomes, not required fields in every section, and no chapter length triggers an automatic halt.

The agent can draft in one pass, build incrementally, or revise existing passages. It can use another layout, omit an unnecessary analogy or glossary, provide requested solutions, and write at an advanced level without reteaching all foundations. Research follows the task's needs and environment requirements rather than a fixed number of searches.

## Existing learning repositories

Briefs, tier labels, metadata, and navigation provide continuity. The agent preserves existing notes and learner progress while replacing instructional placeholders with content. Authorized scope changes can update the brief and plan together.

Practice and quizzes normally leave room for the learner's own attempt. Requested model answers or solutions go in separate, clearly labelled sections; the agent does not invent learner attempts, measurements, or mastery.

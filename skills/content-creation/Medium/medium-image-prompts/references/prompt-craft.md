# Prompt craft

Describe the actual visual: subject, relationships/action, composition, style, palette, background, and relevant constraints. Explain intended meaning without relying on abstract metaphors alone. Keep prompts as short as their complexity permits; no word-count band is needed.

Example: “Two differently sized containers feed one narrow channel, with material visibly accumulating before the bottleneck. Clean editorial illustration, teal and charcoal palette, generous negative space, horizontal composition. Conceptual illustration, not a measured chart.”

State exact text when labels are needed and supported, then inspect spelling and legibility after rendering. Use structured diagrams or layout tools for exact relationships, formulas, brand marks, or dense labels. Choose screenshots/plots from actual evidence for measured results.

Aspect ratio and crop should fit the placement and subject. Allow space for a cover crop or intended title overlay when requested; verify the destination's current image requirements when precision matters.

Negative prompts are optional. Some tools ignore them or lack a separate field; write essential constraints in the main prompt and avoid contradictory requests. Tool-specific syntax belongs only with an identified generator/version.

For each visual, include placement, purpose, prompt, ratio, caption/credit needs, and provisional alt text. Alt text describes the rendered content and function in context; update it after inspection, and provide a longer explanation for a complex diagram. A fixed character limit should not erase essential meaning.

Review for misleading data or documentary claims, accidental marks, illegible labels, inconsistent style, and inaccessible contrast. Generated art may explain a concept, but it cannot certify that an event, benchmark, or interface actually existed.

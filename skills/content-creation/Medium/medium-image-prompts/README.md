# Article Image Prompts

Read an article or supplied brief, plan useful visuals, and write prompt text with placement, composition, style, captions, and provisional alt text. Default output is medium_image_prompts.md.

The number and style of visuals follow the article and user brief. A single cover is valid; white backgrounds, fixed aspect ratios, and bans on all text or people are not universal requirements. Existing explicit house styles are preserved.

Generated art can illustrate concepts. Exact charts, screenshots, architecture, and measured results need real data or reliable structured tools. The output identifies those requirements rather than inventing evidence.

Draft-based placements are labeled provisional. Alt text is checked against the actual asset after rendering. Medium packaging points to current AI-image caption requirements rather than treating disclosure as optional.

[SKILL.md](SKILL.md) covers source selection and routing. [Style tracks](references/style-tracks.md) and [prompt craft](references/prompt-craft.md) are adaptable options. The skill prepares prompts; when actual rendering is requested, continue using the appropriate available image or diagram tools.

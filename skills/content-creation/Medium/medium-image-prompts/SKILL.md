# Article Image Prompts

Choose visuals that clarify or meaningfully complement the article. Produce prompt text and a visual plan; do not claim an image was rendered or inspected when only a prompt exists.

## Establish the source and purpose

Read the user-selected article. If several plausible versions exist, inspect their names and content; modification time alone does not identify the authoritative draft. Ask only if ambiguity matters. A draft or outline can support provisional directions when requested; label placements that will need revisiting.

Identify the argument, audience, important relationships, and any requested visual style. Choose the number of visuals from the article's needs: a single cover or no decorative images may be sufficient. Do not manufacture three to five placements.

## Choose the right medium

Use generative art for editorial imagery, conceptual illustrations, and visual metaphors. For exact data, interfaces, code output, or architecture, specify a real screenshot, reproducible chart, or structured diagram. Synthetic examples may illustrate a concept if clearly labeled; never present invented output as observed evidence.

No blanket ban on text, people, logos, color, or particular backgrounds is needed. Follow the user's brief, asset permissions, privacy, and the chosen tool's capabilities. For accurate marks or readable labels, use supplied assets or reliable layout/vector tooling where appropriate. Avoid misleading endorsements or depictions of actual events as documentary evidence.

## Build a coherent set

Use [style tracks](references/style-tracks.md) as options and [prompt craft](references/prompt-craft.md) for prompt construction. White backgrounds and a limited accent palette are available defaults, not immutable house rules. Preserve an explicit existing house style.

Choose consistent rendering, palette, composition, and detail where the images form a series. Adapt aspect ratio and visual density to each placement; consistency need not mean identical framing.

Each prompt should explain the subject, intended meaning, composition, style, relevant constraints, and desired aspect ratio. Use plain prose by default; add tool-specific parameters only for an identified tool. Negative prompts are optional and tool-dependent.

## Deliver and review

Use [the template](assets/image-prompts-template.md) to write `medium_image_prompts.md` beside the article, or follow the requested format. Include source/version, placements, prompts, captions, provisional alt text, and exact-visual slots with their data/assets required.

For Medium, check current [AI-content policy](https://help.medium.com/hc/en-us/articles/22576852947223-Artificial-Intelligence-AI-content-policy) when publishing guidance is relevant. Generated-image captions should identify AI generation; do not label an unrendered prompt as a finished image.

Check that each visual earns its placement and avoids unintended factual claims. After rendering, inspect actual content, labels, cropping, accessibility, and consistency, and revise alt text accordingly. If rendering is requested, continue with the available appropriate tools; the prompt workflow itself creates no extra approval gate.

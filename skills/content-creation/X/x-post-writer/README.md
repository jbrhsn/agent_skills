# X Post Writer

One independent writing skill for short, medium-length, and long X (Twitter) posts and connected threads. It drafts, revises, and adapts notes, topics, articles, or existing posts while preserving voice, attribution, and factual meaning. Thread writing is a mode of this skill, so no separate x-thread-writer is required.

## Example requests

- “Write a short X post from these notes. Keep my understated tone.”
- “Develop this observation into a medium-length single post with an example.”
- “I can publish longer posts. Turn this article into one sustained X post, keeping its caveats.”
- “Make this explanation a thread of standard-length posts. Choose the length from the material.”
- “Use this strategy brief to adapt my LinkedIn draft for X, and keep the original intact.”
- “Tighten only the second post in this thread. Return the revision inline.”

Short, medium-length, and long are editorial descriptions, not fixed character ranges. The skill respects an explicit format and otherwise chooses a form that suits the material. Longer single posts depend on account capability; threads are checked post by post. Limits and counting guidance are backed by dated [official-source research](references/x-mechanics.md).

## Outputs and cooperation

Folder workflows produce `x_post.md` or `x_thread.md`, with optional matching notes when sources, assumptions, or editorial decisions merit them. Thread delivery labels identify each post and are excluded from the text to publish. Explicit paths, distinct variant names, and inline-only requests are supported. Original sources and unrelated edits are preserved.

The skill works without any other skill, strategy document, login, or analytics. It can use an optional `x_strategy.md`, idea-research results, keyword research, LinkedIn or Medium drafts, and visual plans. [Handoff guidance](references/handoffs.md) keeps that context optional and makes useful editorial notes available to later workflows.

There are no fixed hook formulas, thread sizes, approval phases, or performance promises. Exact X fit requires a compatible counting method or composer check; an approximate count is labeled. Writing does not authorize publishing, scheduling, account changes, or interaction with other accounts.

See [SKILL.md](SKILL.md) for the workflow and [composition guidance](references/composition.md) for the different writing modes.

## Validation

Exercised in an independent agent drafting session on 2026-09-19 using the repository's actual unified-writer work as source material: short, medium-length, and long single posts plus a thread. A follow-up exercise verified removal of an unmeasured percentage and precedence of the current request over conflicting strategy context. Skill validation, local-link checks, and the multi-platform sync dry-run passed. This covers observed drafting behavior; account-specific composer validation and publishing performance were not tested.

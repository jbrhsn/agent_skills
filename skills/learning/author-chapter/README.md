# Author Chapter

Write or revise teaching material at the depth the learner needs: a standalone chapter, tutorial, guide, assessment, or files from a learning repository.

## Approach

The skill uses the requested outcome, reader's starting point, and existing brief to choose an approach. Clear takeaways, concrete examples, manageable units, and retrieval practice are useful defaults. They are not required fields in every section, and no chapter length triggers an automatic halt.

The agent can draft in one pass, build incrementally, or revise existing passages. It can use another layout, omit an unnecessary analogy or glossary, provide requested solutions, and write at an advanced level without reteaching all foundations. Research follows the task's needs and environment requirements rather than a fixed number of searches.

## Existing learning repositories

Briefs, tier labels, metadata, and navigation provide continuity. The agent preserves existing notes and learner progress while replacing instructional placeholders with content. Authorized scope changes can update the brief and plan together.

Practice and quizzes normally leave room for the learner's own attempt. Requested model answers or solutions go in separate, clearly labelled sections; the agent does not invent learner attempts, measurements, or mastery.

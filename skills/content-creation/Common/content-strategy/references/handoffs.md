# Independent work and optional handoffs

The skill accepts a request directly and includes idea discovery, evidence evaluation, prioritization, planning, and review. Other skills and files are optional. Read only supplied or clearly associated context; a file's existence does not select the platform or authorize a whole pipeline.

| Input or downstream skill | Useful exchange |
|---|---|
| `idea-research` | Candidate angles, source provenance, dates, limitations, and optional source scaffolds |
| `keyword-research` | Search intent and vocabulary for a defined topic when relevant |
| `linkedin-post-writer` | Selected LinkedIn text-post brief, audience, angle, evidence, voice, constraints |
| `medium-article-writer` | Article thesis, reader promise, research, author material, packaging requirements |
| `x-post-writer` | Selected post/thread brief, format preference, account assumptions, evidence and voice |
| `medium-image-prompts` | Visual needs for an actual article or sufficiently developed brief |
| Existing drafts and notes | Follow-up ideas, factual gaps, source material; no inferred publishing performance |

`content_strategy.md` is the common plan convention. Accept older `x_strategy.md`, inline briefs, and custom paths without requiring conversion. A writer can consume one selected item and its associated strategy context; it need not read every research record or produce every scheduled item. Provide the brief inline when a writer does not recognize the filename. Current instructions override older strategy preferences.

Keep item IDs, sources, uncertainty, I/we attribution, and author-input requirements with each brief so it works when extracted. Writers remain responsible for final copy, factual support, voice, formatting, and platform fit. A planned document, video, newsletter, or X Article may require work beyond the listed writers; do not silently reinterpret it as a supported text format.

Creating the plan does not launch all downstream skills. If drafting is also requested, use the relevant available skill for the requested items, preserving source notes and unrelated drafts. Without installed writers, the plan and briefs remain complete deliverables. Later reviews may use actual results supplied by the user; a calendar or finished draft alone supplies no performance evidence.

# Content Fact Checker

Validate and refine `source.md`, an initial draft, article brief, essay, or post through claim-level web research. The skill preserves the author’s core message, opinions, voice, tone, intended audience, and lived experience while making weak or broad factual statements more precise and supportable.

It evaluates explicit and implied claims, including statistics, comparisons, forecasts, causal assertions, current facts, and factual premises behind opinions. Research checks both supporting and conflicting evidence, preferring primary sources, official reports, original research, and transparent surveys. Each finding distinguishes supported, partially supported, unsupported, contradicted, unverified, and personal/editorial material; an incomplete search is never presented as disproof.

The refinement uses the smallest faithful correction. It adds scope, population, period, baseline, methodology limits, or attribution only when the evidence supports the author’s existing point. Personal experience remains personal, and central factual conflicts are surfaced for author review rather than silently changing the thesis. Facts and statistics receive inline numbered references by default, or claim-to-source notes when the requested publishing format cannot include URLs.

When editing is requested, the skill updates the requested file or returns the refined text with a concise summary of material corrections, qualifications, evidence added, and unresolved claims. For critique-only requests, it returns a claim audit and suggested corrections without changing the draft. It does not create extra files unless the user asks or an existing publishing-note convention requires them.

See [SKILL.md](SKILL.md) for the workflow and [claim-audit.md](references/claim-audit.md) for claim categories, evidence checks, and safe revision patterns.
